# Plans

Working plans for this repo live here as directories (one per plan, per
the plan-* skill family's conventions), but they are **never
committed**: plan trails are person-specific execution history, and
nothing person-specific is tracked in this library. A finished plan is
archived - directory and all - to a separate archive repo by
`plan-archive`.

What IS tracked here, deliberately small:

- `ARCHIVE.md` - one tombstone line per archived plan: name, date,
  destination, final commit.
- This README.

If you see plan directories beside these files in a checkout, they are
untracked local state belonging to whoever is running the plans.
